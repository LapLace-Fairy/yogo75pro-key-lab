- [ ] 验证写屏、读电量及原生电量显示。
  - 验收：输出 2.4G/有线连接能力矩阵、读写限制、写入持久性及恢复方式；未测试项标记未知。
  - 验证：先检查现有协议，再实机单次显示测试并恢复；依赖：上一项。
- [ ] 核实 Codex 与 ZCode 的桌面会话事件。
  - 验收：分别记录进行、完成、权限审批、需要用户回答的问题、恢复、失败及多会话事件是否可观察；明确 CLI 和桌面覆盖差异。
  - 验证：分别制造真实事件并对照应用界面，确认不会自动批准；依赖：无。
- [ ] 验证两个实体键的映射及应用激活。
  - 验收：确认键值、冲突、启动和已运行时切前台，记录权限及多窗口限制。
  - 验证：实际按键操作；依赖：无。

## 1. 快捷键

- [ ] 实现可配置的应用启动/激活。
  - 验收：按键分别打开两个应用；已运行时激活，不新增进程；失败可诊断。
  - 验证：关闭、运行、最小化、多个窗口及不同空间分别测试；依赖：按键验证。

## 2. 屏幕与模式

- [ ] 实现设备发现、最小图案和断连恢复。
  - 验收：在已验证连接方式下显示可辨图案；断开重连恢复；可还原原配置。
  - 验证：真机插拔/休眠唤醒，检查 ATK HUB 共存；依赖：设备验证。
- [ ] 实现电量模式和切换。
  - 验收：6×6 屏幕使用 4×5 图标和颜色梯度显示 100%、80%、60%、40%、20% 五档；无可靠读数时不显示虚假电量。仅支持原生模式时明确记录为降级，切回编程模式恢复状态。
  - 验证：测试 2.4G 和有线的电量读取、五档边界、0%、模式切换及读数不可用场景；依赖：设备验证。
- [ ] 实现 macOS 原生可视化界面。
  - 验收：用户可在界面切换编程/电量模式并即时更新键盘；界面展示连接状态、当前显示预览及必要权限提示。
  - 验证：两种连接方式分别检查切换、断连提示与重连恢复；依赖：屏幕和电量模式实现。
