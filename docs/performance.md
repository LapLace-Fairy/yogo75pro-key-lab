# 空闲 CPU 测量

测量对象是当前 Mac 上已连接 2.4G 接收器、没有待确认提醒的 Yogo Key Lab 主进程。CPU 时间包含该进程的用户态与内核态，不包含独立的 Hook 子进程。`ps` 累计 CPU 时间精度为 0.01 秒；样本期间 Codex 仍在运行，可能有少量状态事件。

| 版本和条件 | 墙上时间 | 主进程 CPU 时间增量 | 说明 |
| --- | ---: | ---: | --- |
| 原版：0.75 秒持续发帧、2 秒扫描状态文件 | 124 秒 | 2.56 秒 | 基线，约相当于 75 秒 1.55 秒 |
| 初次调整：仍持续发黑帧 | 75 秒 | 1.61 秒 | 未达标；同时观察到设备偶发拒绝帧 |
| 事件驱动：空闲不持续发黑帧 | 210 秒 | 0.10 秒 | 更长的连续区间内低于 0.5 秒 |
| 事件驱动：第二段 | 89 秒 | 0.12 秒 | 同一进程的后续区间，低于 0.5 秒 |
| App 内 CPU 自测 | 75.0 秒 | 0.095 秒 | `getrusage` 测量主进程用户态与内核态时间，达标 |
| YogoLab 新界面 Debug 版 | 75.0 秒 | 0.111 秒 | 2.4G 已连接、无待确认；`getrusage` 测量主进程，达标 |

黑屏停止推帧后，用户目视确认至少 10 秒保持熄灭。更长时间、休眠唤醒、有线和其他固件版本仍需验证。

Debug 构建的「测量空闲 CPU」按钮使用进程自身的 `getrusage` 采样用户态加内核态 CPU 时间，并以系统运行时间计算 75 秒区间；测量期间请勿触发提醒或操作界面。测量覆盖 App 主进程，不包含 Hook 子进程，也不能代表不同机器的所有使用情景。正式版不显示此按钮。
